Privacy and network activity

This documentation website is static HTML hosted by GitHub Pages. It does not add advertising pixels, analytics scripts, a registration form or an application database. GitHub operates the hosting infrastructure and may process request information under its own policies; this project cannot make promises on GitHub’s behalf.

Miner commands and network access

info --json reads public capabilities locally. A benchmark performs local synthetic work; it does not earn coins. The build process downloads dependencies from their documented sources. An explicitly launched mine command connects to the selected mining pool, sends the public mining identity and protocol work, and receives jobs and share responses. The pool sees the connection’s network address.

When the optional developer contribution is enabled, developer work uses a separate, disclosed LuckyPool connection. It does not require your wallet seed, private key or wallet password. The miner does not manage wallet recovery or exchange withdrawals. Pool operators have their own retention and payment rules.

Local and public records

Self-test and fee-accounting records are local. Console logs may contain public payout identities and worker names. Remove those and local filesystem paths before sharing logs. Published performance evidence is sanitized and does not include private host inventories or reusable access credentials. See the AI installation guide for the authorized setup sequence.
