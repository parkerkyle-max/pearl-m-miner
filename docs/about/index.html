About Pearl M-Miner and project support

Pearl M-Miner is an independent open-source Pearl (PRL) GPU miner maintained under the GitHub account parkerkyle-max. It focuses on exact Metal computation on Apple Silicon. Its implementation is derived from pearl-metal-miner; the repository preserves upstream attribution and license notices.

The source is Apache-2.0. The default developer contribution is optional and uses 1% of completed valid GPU scan time. It is disclosed in the CLI and source, can be disabled with --dev-fee 0, and is not a condition of the license. Support helps fund testing on real hardware, correctness checks and maintenance.

Evidence before performance claims

Read the device qualification table and benchmark methods. An offline speed test, an accepted pool share and realized income are different measurements. We do not claim that every M-series chip has been tested.

Contact and bug reports

The public support channel is GitHub Issues. Include the release, chip/GPU cores, memory, macOS version, exact command with your account removed, and the failing self-test or sanitized log. Do not post wallet recovery material, API credentials, private keys or unrelated process inventories. For sensitive reports, see SECURITY.md before posting.

There is no guaranteed support response time, profitability promise, Apple endorsement or mining-pool listing implied by this website.
